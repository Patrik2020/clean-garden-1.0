# Clean Garden 1.0

Portfólió-demo weboldal egy **fiktív magyar kertgondozó és kertépítő kisvállalkozás** számára.

> A Clean Garden nem valós vállalkozás. A nevek, árak, vélemények, referenciák és elérhetőségek demonstrációs célúak.

## Oldalak
- `index.html` – főoldal
- `szolgaltatasok.html` – szolgáltatások és irányárak
- `referenciak.html` – fiktív projektportfólió
- `kapcsolat.html` – ajánlatkérő űrlap
- `adatkezeles.html` – demo adatkezelési tájékoztató
- `404.html` – egyedi hibaoldal

## Technika
Vanilla HTML, CSS és JavaScript, külső framework nélkül. Mobil-first reszponzív kialakítás, szemantikus HTML, SEO meta adatok, Open Graph, JSON-LD demo LocalBusiness séma, sitemap, robots.txt és webmanifest.

## Futtatás
Nyisd meg az `index.html` fájlt, vagy publikáld GitHub Pages segítségével.
